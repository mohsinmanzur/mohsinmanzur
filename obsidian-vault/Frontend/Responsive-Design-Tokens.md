# Responsive Design & Styling Tokens

Styling rules using Tailwind CSS v4 and CSS variable placeholders.

## Design Placeholders
Colors and typography are defined as CSS variables in `src/app/globals.css`:
- `--color-primary`, `--color-secondary`, `--color-accent`, `--color-muted`
- `--font-sans`, `--font-heading`, `--font-mono`

## Breakpoints & Adaptability
All components must be responsive across standard breakpoints:
- `sm:` (640px)
- `md:` (768px)
- `lg:` (1024px)
- `xl:` (1280px)
