# SEO Strategy

Search engine optimization guidelines for the Portfolio project.

## Implementation Standards
- Descriptive `<title>` templates and meta descriptions on every page
- Semantic HTML tags (`<main>`, `<header>`, `<section>`, `<article>`, `<footer>`)
- OpenGraph tags and Twitter card metadata
- Single primary `<h1>` element per route
- Pre-rendered Server Components for fast indexing
